# 🛒 Webstore

A full-stack webstore application built to learn and apply modern frontend and backend development practices.  
This project focuses on clean architecture, authentication, and real-world API interaction.

---

## ✨ Tech Stack

### Frontend
- React
- TypeScript
- Vite
- CSS Modules
- Fetch API

### Backend
- Kotlin
- Spring Boot
- Spring MVC
- Spring Data JPA
- PostgreSQL
- Gradle

### Authentication
- JWT (stored in HTTP-only cookies)
- Custom annotations & AOP for request authentication
